One sentence of horror, under 200 characters, written to scare a reader in
a single breath. An entry for [make.fun's "One Line, One Chill" bounty](https://make.fun/bounty/u-azazex-one-line-one-chill-6d4d5488).

## The line

> The radiologist went quiet when the second spine on my MRI curled to spell my name.

## How it works

`main.py` takes no arguments and writes that one line to `/output/entry.txt`
— the same bytes on every run, no network, no input, no randomness.

```sh
python3 main.py
cat /output/entry.txt
```
