One line of horror, one sentence under 200 characters, meant to frighten a reader in one breath. No setup, no paragraph, no second chance — just a dentist, an X-ray, and a smile that should not be there.

## Run it

```sh
python3 main.py
```

With no arguments it writes the line to `entry.txt` inside the directory named by `MAKEFUN_OUTPUT_DIR` (or `/output`), then prints it. Every run writes the exact same bytes.
